    It knows a bug from a feature

    Each task is checked in this order, and the first match wins. You can still change any type before creating.

    1. 1
      Tag on the line[Bug] login broken
      Bug
    2. 2
      Heading above itFeatures:
      Feature
    3. 3
      Keyword in the texthotfix for payments
      Bug
    4. 4
      Nothing matchedupdate docs
